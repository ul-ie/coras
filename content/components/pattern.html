Description

The pattern component is a configurable container for UL's Graphic Patterns, which are inspired by the campus topography, the river Shannon and the living bridge.

They are decorative and should be used to enhance a design but should never obscure any information. Our patterns should only ever be used in our primary or mono colours.

Syntax

Use the include tag to inject a pattern, and the only keyword if it needs to be protected from outside scope.

{{ html("
{% include 'ul:pattern' with {
  property: 'value'
  ...
} only %}
")}}

Properties

A pattern has one mandatory and six optional properties.

{% include '@layouts/component-props.html' %}

Examples

Below are some examples of how to customise the colour, size, add a clip-path and inject further modifier classes where needed.

Fill and Size

The default fill of a pattern is fill-white and the default size is w-48 h-auto (192px in width with automatic height).

In the below example, the fill and size are modified for each pattern.

{% include '@components/pattern/pattern.twig' with { name: '2C', size: 'w-36 h-auto', fill: 'fill-heritage' } only %} {% include '@components/pattern/pattern.twig' with { name: '2B', size: 'w-48 h-auto', fill: 'fill-modern' } only %} {% include '@components/pattern/pattern.twig' with { name: '2A', size: 'w-64 h-auto', fill: 'fill-green' } only %} 
{{ html("
{% include 'ul:pattern' with {
  name: '2C',
  size: 'w-36 h-auto',
  fill: 'fill-heritage'
} only %}

{% include 'ul:pattern' with {
  name: '2B',
  size: 'w-48 h-auto',
  fill: 'fill-modern'
} only %}

{% include 'ul:pattern' with {
  name: '2A',
  size: 'w-64 h-auto',
  fill: 'fill-green'
} only %}
")}}

Clip-path

Pattern components also support custom clipping, via clip-path syntax. In the following example a polygon shape is used to clip the top right portion of the pattern:

{% include '@components/pattern/pattern.twig' with { name: '1C', fill: 'fill-heritage', clip_path: 'polygon(0% 0%, 80% 0%, 80% 30%, 100% 30%, 100% 100%, 0% 100%)' } only %} 
{{ html("
{% include 'ul:pattern' with {
  name: '1C',
  fill: 'fill-heritage',
  clip_path: 'polygon(0% 0%, 80% 0%, 80% 30%, 100% 30%, 100% 100%, 0% 100%)'
} only %}
")}}

Customisation

Further customisation can be done via the modifiers property. In the below example the pattern is placed behind another partially-transparent div.

{% include '@components/pattern/pattern.twig' with { name: '1A', modifiers: 'absolute top-7 left-7' } only %} 
{{ html("


  {% include 'ul:pattern' with {
    name: '1A',
    modifiers: 'absolute top-7 left-7'
  } only %}
  



")}}
